# Homeili
The idea is to learn how a search engine works, learning from Meilisearch internals.
Also, make use of AI for writing validation tests, NOT the implementation.

## Stuff to learn
- Inverted index
- FSTs for dictionaries
- Roaring bitmaps
- Ranking algorithm:
    1. Matches all terms
    2. Typo count
    3. Proximity
    4. Attribute weight
    5. Prefix/exact
    6. Exact match
- Filtering
- Faceting
